Что советую

Основа — Е: ввод говорит на языке списка, вся группа видна, ничего нового учить не надо. Клавиши веса из Д уже там; саму линейку добавить вторым слоем — потянул число вбок, поехала шкала. Г оставить кнопкой «⊙ блины»: для штанги это лучший калькулятор, но не основной ввод. Ж — самый тесный, беру только если хочется полностью уйти от клавиш.
