# body-muscles

Файл `app/src/main/kotlin/com/looker/kenko/ui/components/body/BodyRegions.kt` содержит
анатомические SVG-контуры из библиотеки [body-muscles](https://github.com/vulovix/body-muscles)
(автор — Viktor Vulovic), распространяемой по лицензии Apache License 2.0.

Контуры переведены в Kotlin и сопоставлены с группами мышц приложения; сами данные путей
не изменялись. Полный текст лицензии — в `licenses/body-muscles-LICENSE.txt`.
