# react-native-body-highlighter

Файл `app/src/main/kotlin/com/looker/kenko/ui/components/body/BodyRegions.kt` содержит
контуры человеческой фигуры и мышц из библиотеки
[react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter)
(автор — ELABBASSI Hicham), распространяемой по лицензии MIT.

Пути переведены в Kotlin и сопоставлены с группами мышц приложения; сами данные путей
не изменялись. Полный текст лицензии — в `licenses/body-highlighter-LICENSE.txt`.
